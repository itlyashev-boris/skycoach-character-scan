# Character Scan: анализ персонажа WoW с кросс-сейлом услуг SkyCoach

Прототип к блоку «AI» тестового задания. Собран на вайбкоде (Claude Code) за один день: один файл `index.html`, без сборки и бэкенда.

## Что делает

1. Принимает персонажа World of Warcraft одним из трёх способов:
   - **по имени**: регион, сервер и имя, или ссылка на raider.io / worldofwarcraft.com;
   - **вручную**: уровень, уровень предметов, рейтинг M+, прогресс рейда, тир-сет;
   - **демо**: пять вымышленных персонажей на разных стадиях сезона.
2. Загружает публичный профиль из [Raider.IO API](https://raider.io/api): экипировку по слотам, чары, тир-сет, рейтинг Mythic+ и лучшие ключи, прогресс рейдов, достижения AOTC / CE.
3. Считает **индекс готовности к сезону** (0–100): экипировка 35%, Mythic+ 30%, рейд 25%, тир-сет и чары 10%.
4. Прогоняет персонажа через **движок правил** и показывает до 5 рекомендаций услуг SkyCoach с приоритетом, объяснением в цифрах и ожидаемым результатом.
5. Предлагает **пакет** из топ-3 услуг со скидкой и тизер **Skycoach Membership** (связка с блоком 5 задания).
6. Пишет **события аналитики** воронки (видны в блоке внизу страницы).

## Логика кросс-сейла

Каждое правило — это условие, услуга, приоритет и объяснение. Рекомендации сортируются по приоритету, дубли по одной услуге убираются.

| Ситуация | Правило | Услуга SkyCoach |
|---|---|---|
| Уровень ниже 90 | `level_cap` + кампании + гир после прокачки | Leveling, Midnight Campaigns, Full Gear |
| Уровень предметов < 295 | `gear_low` | Full Gear, Delves |
| 2+ слота отстают от среднего на 12+ | `gear_weak_slots` | Mistcrests Farm |
| 1 слабый слот | `gear_weak_slot_craft` | Gear Crafting |
| Нет рейтинга M+ в сезоне | `mplus_start` | Mythic+ 2–20 |
| Рейтинг ниже следующего порога (2000 / 2500 / 3000 / 3500) | `mplus_<порог>`, +8 к приоритету, если до порога ≤ 250 | Keystone Master / Hero / Legend / Myth |
| Героик Venomous Abyss не закрыт | `raid_heroic_full` / `raid_aotc` | VA Heroic / Ahead of the Curve |
| Героик закрыт, ilvl ≥ 328 | `raid_mythic` | Single Bosses / VA Mythic |
| Не закрыты мини-рейды (и основной рейд) | `raid_mini` / `raid_all_bundle` | Kith'ix / All Raids Bundle |
| Меньше 2 или 4 частей тир-сета | `tier_set` | VA Single Bosses |
| Всё закрыто (M+ ≥ 3000 и героик 8/8) | `top_collections`, `top_glory`, `top_coaching` | Маунты, Glory, коучинг |

Принципы:
- **Сначала блокеры.** Пока персонаж не 90 уровня, рейды и ключи не предлагаются, только прокачка и то, что нужно сразу после неё.
- **Не продавать недостижимое.** Героик-рейд не предлагается при уровне предметов ниже 295, мифик — ниже 328.
- **Бесплатные советы рядом с платными.** Отсутствующие чары, пустые слоты, просроченные ключи — это советы без продажи. Они повышают доверие к платным рекомендациям.
- **Топ-игроку не навязываем буст.** Предлагаем коллекции, мета-достижения и коучинг: это удержание, а не разовая продажа.
- Все ссылки на услуги несут UTM: `utm_source=character_scan&utm_medium=crosssell&utm_content=<id правила>`. Конверсию можно считать по каждому правилу.

## Корнер-кейсы

| Кейс | Поведение |
|---|---|
| Пустое поле, пробелы, цифры, имя длиннее 12 букв | Ошибка у поля, запрос не уходит |
| Ссылка вместо имени (raider.io, worldofwarcraft.com) | Разбирается на регион / сервер / имя |
| Сервер с апострофом или пробелом (Kel'Thuzad, Twisting Nether) | Нормализуется в slug |
| Русский сервер (Ревущий фьорд, Гордунни) | Raider.IO принимает кириллицу; запасной вариант — транслит |
| Сервер не существует | «Сервер не найден» с подсказкой о написании |
| Персонаж не найден в выбранном регионе, но есть в другом | Предложение открыть в нужном регионе одной кнопкой |
| Персонаж не найден нигде | Три вероятные причины (опечатка, уровень ниже 90, давно не заходил) + ручной ввод и демо |
| Персонаж ниже 90 уровня | Raider.IO его не хранит → ручной ввод → сценарий прокачки |
| Профиль без экипировки | Анализ по рейтингу и рейдам, сообщение вместо таблицы |
| Нет рейтинга M+ в этом сезоне | Отдельная рекомендация «начать M+», индекс считается по известным данным |
| Устаревшие данные (> 14 дней) | Предупреждение: зайти в игру и обновить профиль |
| Пустые слоты, нет чар, просроченные ключи | Бесплатные советы |
| Raider.IO: 429, 5xx, таймаут 12 с, невалидный JSON | Понятное сообщение, кнопки «Повторить» и «Ввести вручную» |
| Нет сети / внешние запросы заблокированы | Сообщение + ручной ввод и демо работают офлайн |
| Портрет персонажа не загрузился | Инициал в цвете класса |
| Повторный запрос того же персонажа | Кэш 10 минут в localStorage |
| Глубокая ссылка `?region=eu&realm=...&name=...` | Анализ запускается сразу, URL можно отправить другу |
| Танк или лекарь | Совет про коучинг вместо буста: им проще найти группу |
| Мобильный экран | Одна колонка, без горизонтального скролла |

## Ограничения прототипа

- Пороги уровня предметов и рейтинга для Midnight Season 2 приблизительные и вынесены в `CONFIG` в начале скрипта.
- Цены не показываются: на сайте SkyCoach они зависят от опций. Скидки на пакет (10%) и подписку (7%) — пример механики.
- Raider.IO хранит только персонажей максимального уровня, которые заходили в игру в этом сезоне.
- Нет бэкенда: аналитика выводится в журнал на странице, а не в трекер.
